# codex 2.0

Codex is an AI-powered multimodal document assistant designed to interact with uploaded documents and images through a conversational interface. It combines **RAG (Retrieval-Augmented Generation), LangChain, vector embeddings, and LLMs** to understand user-provided content and generate context-aware responses. The project focuses on a clean, modern UI while providing capabilities such as document analysis, intelligent question answering, and contextual dialogue.

**Tech Stack:** Python • Streamlit • LangChain • RAG • Vector Database • LLMs • Multimodal AI
